# MILo Video to 3D Web App

This app uploads a video, reconstructs a target object as a 3D mesh with MILo, and exports the result as OBJ or USDA.

It provides a browser-based workflow for turning short video footage into reusable 3D geometry for further processing.

動画をアップロードし、MILo を使って動画内の対象を 3D メッシュとして再構成する FastAPI ベースの Web アプリです。
